
# Sales & Revenue Analysis Dashboard

Built an interactive Excel dashboard to analyze sales and revenue performance using Pivot Tables, Charts, KPIs, and Slicers.

## Features
- KPI Tracking
- Revenue Analysis
- Interactive Filters & Slicers
- Customer Insights
- Sales Trend Visualization

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
